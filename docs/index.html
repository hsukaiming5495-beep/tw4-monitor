    四檔並列

    訊號由均線、MACD、KD、RSI、布林、量能、法人與融資券、月營收與本益比加權計算，僅作為紀律化進出的輔助，不構成投資建議。 放空前確認該股可融券（上詮、華星光為上櫃股）、避開停券期間（股東會、除權息前），並一律預掛停損。 研究筆記為 2026/09 公開資訊整理；行情由 GitHub Actions 每個交易日盤後自動更新。

    資料怎麼更新

    這個頁面不能直接連線券商或交易所，行情由你電腦上的收集器抓取後載入：

    雲端版由 GitHub Actions 每個交易日 18:30 自動抓取 FinMind 資料（股價、月營收、本益比、三大法人、融資券），更新本頁並推送 Telegram 盤後訊號；盤中每 15 分鐘檢查觸價。

    要立即更新：到 GitHub 儲存庫 Actions → tw4-daily → Run workflow。也可手動按「載入資料」選任一份 tw4_data.json。

    訊號怎麼讀

    做多：突破＝收盤創 20 日新高且量大於均量 1.5 倍；做多：拉回＝多頭排列（價>月線>季線）下回測月線、KD 金叉或 MACD 柱轉強。放空：跌破與放空：反彈空為鏡像條件。過熱＝RSI>75 且站上布林上軌，不追多、等轉弱訊號試空。

    停損 2×ATR、目標 2×／4×ATR。回測列出同一規則在過去一年的 10 日後報酬，樣本少時僅供參考。
